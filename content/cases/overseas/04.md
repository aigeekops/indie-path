# 验证目标国家的可用性与交付

## 学习要点

- 目标国家访问
- 英文与日期表达
- 交付及支持范围

## 实践步骤

- 先完成共用verify、usability、ship任务中的检查、版本发布和恢复；保留原技术栈，不为出海重学。
- 让首个目标国家的用户检查英文输入、错误、日期和打印结果，记录其能否独立完成；国内自己打开不能替代目标环境。
- 说明数据处理、保留/删除方式及支持时区；面向国家变化时重新核对具体交付与适用要求。
- 记录独立完成、帮助和失败；只修本地化阻塞，再用相同核心任务复测，不把翻译按钮等同完成交付。

```text
版本0.1；正常/空/缺字段/跨月/长文本/打印六组样例通过。

开放前待办：托管商业用途条款、支持主体、实际收集的数据与面向国家的要求。
GitHub Pages仅用于本学习站或符合规则的教学演示，不作为该商业产品的免费SaaS托管。
```

## 不合格示例

不合格：把英文首页能打开、托管显示部署成功等同真实客户能完成任务。

## 完成标准

- 目标环境完成核心任务
- 版本/配置/恢复有记录
- 数据收集边界明确
- 托管条款与地区事项已核对
