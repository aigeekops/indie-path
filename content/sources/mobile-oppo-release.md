# OPPO 开放平台

## 选读范围

从首页进入开发者接入与应用上架相关板块，确认资质要求、应用上架审核节点，以及与华为、小米流程不同的地方。

## 阅读终点

形成一份针对 OPPO 的**独立提交清单**（不能照抄小米），说清包名、隐私政策、资质文件与测试账号需要怎么准备。

## 访问说明

官方中文文档公开免费；实际操作需要 OPPO 开发者账号。涉及版号、资质和广告变现的部分，文档不能替代平台自己的判定。

## 核验范围

已确认首页入口可达、标题为「OPPO 开放平台-OPPO 开发者服务中心」（2026-10-25 实测 HTTP 200）。**未通读上架审核条款，未完成任何一次提交**；具体资质清单以你登录开发者后台后看到的为准。
