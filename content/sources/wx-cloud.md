# 腾讯云开发：微信小程序与小游戏云端能力入口

## 选读范围

按所选产品进入“微信小程序”或“小游戏”框架接入，再查云函数、数据库、环境配置、日志监控与当前计费。先确认是否确有云端需求。

## 阅读终点

只为跨设备数据、共享数据、受信服务端计算或订单校验接入必要能力，并记录环境、身份来源和成本边界。

## 访问说明

文档免费公开；云环境、数据库、存储、函数与外部 API 可能计费。免费阅读不等于免费生产运行，不自动开通付费套餐。

## 核验范围

已读取文档中心产品能力与两类框架入口；具体框架子页本次抓取超时，未运行接入。小程序原生云调用与其他平台自定义登录方案有差别，按实际 SDK 版本选对应文档。
