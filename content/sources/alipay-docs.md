# 支付宝文档中心

## 选读范围

按「接入准备 → 应用创建 → 密钥配置 → 下单／支付」的顺序定位官方文档，重点记录：应用类型、密钥与证书要求、回调通知方式。

## 阅读终点

说清一次收款要经过哪几步、每一步要提交什么凭证，并能指出官方文档里"哪些步骤不需要用户资质、哪些需要开通产品权限"。

## 访问说明

官方文档中文公开免费；沙箱与线上环境的差别以文档当期说明为准，不要把沙箱跑通写成"支付已上线"。
