# Google Play · 创建、设置与发布应用

## 选读范围

创建应用、软件包与签名、版本号、应用内容和商品详情；沿页面指引核对当期目标 API 要求。

## 阅读终点

准备可签名的发布产物与完整资料，分清草稿、测试和正式分发状态，并记录发布地区。

## 访问说明

官方中文帮助免费；操作需要 Play 管理中心账号。Google Play 的 App Bundle 流程不能直接作为国内各安卓商店的上传规范。

## 核验范围

已读取 App Bundle、包名、签名、版本及商品详情说明；未上传应用。未固化会随时间变化的目标 API 数字，提交时应按官方当前要求核对。
