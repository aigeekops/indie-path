# 微信官方：小程序与小游戏预览、上传说明

## 选读范围

项目类型、预览、代码上传、编译设置与版本记录。小程序使用 miniProgram，小游戏使用 miniGame；初次发布可先用开发者工具界面，不必先搭建 CI。

## 阅读终点

能区分开发包、体验版本、审核结果与线上版本，记录一次实际上传和真机体验结果。

## 访问说明

公开免费说明及工具；代码上传需自己的 AppID、权限和安全配置。私钥只保存在安全环境，不放到学习成果或公开仓库。

## 核验范围

已读取官方 README 的项目类型、预览、上传和密钥说明。工具上传不等于公众平台审核或发布成功；未代用户上传代码、申请资格或发布。
