# 腾讯开放平台（应用分发）

## 选读范围

从首页进入开发者接入与应用发布相关板块，确认注册开发者、提交应用、审核发布各自要求的资料，特别注意它要求提交的资质文件与其他国内安卓商店有何不同。

## 阅读终点

形成一份针对腾讯渠道的**独立提交清单**，并写清：它与已列出的小米、华为、OPPO、vivo 清单相比，多出或少了哪几项。

## 访问说明

官方中文文档公开免费；实际操作需要开发者账号并通过实名核验。游戏类产品的发布要求与普通应用不同，不共用同一份材料。

## 核验范围

已确认首页入口可达、页面标题为「腾讯开放平台beta｜开放成就梦想」（2026-10-25 实测 HTTP 200）。**未通读上架条款，未完成任何一次提交**；具体资质清单以你登录开发者后台后看到的当期页面为准。
