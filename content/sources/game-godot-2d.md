# Godot 4.5 · 你的第一个 2D 游戏

## 选读范围

设置项目、玩家场景、敌人、主场景与游戏信息显示。已有经验可对照官方完整示例。

## 阅读终点

做出有输入、状态、计分和结束的一局原型，再用真实玩家观察玩法。

## 访问说明

官方中文教程免费；需要基础编程经验，安装引擎和目标平台工具另行准备。

## 核验范围

读取固定 4.5 版本的教程目录、前置条件与示例入口；没有把移动 stable 链接称为已核验的最新版本。此教程本身不是商店发行或微信小游戏适配指南。
