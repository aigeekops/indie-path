# Cocos Creator 3.8 LTS · 第一个 2D 游戏

## 选读范围

搭建环境、创建主角、脚本与输入、地图和规则反馈。熟悉 TypeScript 的读者可从可玩原型开始。

## 阅读终点

把一局规则实现为可运行的 2D 游戏；手机触控与小游戏环境再单独验证。

## 访问说明

官方中文分步教程免费；引擎、素材和插件的实际使用条款分别核对。

## 核验范围

读取教程正文与版本目录。教程部分使用鼠标输入，不能据此声称已经验证手机触控；它是引擎入门，不代表游戏商业表现。
