# 建立一组 AI 输出评估样本

## 为什么做

顺眼的输出不一定可用。把验收标准落实到具体输入和可核对的结果，才能比较提示词与模型改动。

## 开始条件

已有 AI 任务定义和可合法使用的脱敏样例。可评估保存的输出；真实调用会产生供应商费用。

## 学习要点

- 代表性样本与边界情况
- 人工判据与自动检查
- 留出样本与回归比较

## 可运行起点

```text
一、先定义"可用"（四项分开写）
事实正确：______（哪类事实必须对，错了就是严重错误）
必要字段：______（缺一不可的字段）
格式：______（结构 / 长度 / 语言）
不可接受错误：______（编造金额、越权、拒答关键问题…）

二、收 12 条样本（真实脱敏，不用编造）
样本ID | 类别（正常/缺信息/长输入/矛盾） | 脱敏来源 | 参考事实 | 允许变化 | 调试/留出
S01 | | | | | 调试
S02 | | | | | 调试
...
S12 | | | | | 留出

三、先人工写参考判断（不看模型输出）
每条写：必须保留的事实、允许变化的表达、严重错误红线。
写完再跑模型，避免被输出带偏。

四、同条件比较两版
固定：输入、模型设置、预算
样本 | 版本A 输出与判定 | 版本B 输出与判定 | 通过项 | 严重错误 | 耗时 | 费用
S01 | | | | | |
...
逐条填，不用平均分掩盖严重错误。

五、发布决定
严重回归：______（单列，不摊进平均分）
留出集是否被调试污染：是 / 否
发布 / 不发布：______
覆盖缺口：______（样本量、类别、人群）
```

## AI提示词包

```text
第一轮 · 只列样本类别
我的任务是 ______（粘贴）。请列出应覆盖的样本类别：正常、缺信息、长输入、矛盾输入；每类给一个"该收什么样的真实材料"的描述。
硬约束：不要生成样本内容，不要编造用户数据。

第二轮 · 只生成评分表骨架
按"事实正确 / 必要字段 / 格式 / 严重错误"生成评分表骨架，判定列留空。
硬约束：不要替我判定对错；不要给分数权重。

第三轮 · 聚类失败类型
这是一批失败输出（粘贴）。请按失败类型聚类，并指出哪一类属于严重错误。
硬约束：不得评价"整体质量不错"；不得用平均分掩盖单条严重错误。

第四轮 · 检查覆盖缺口
这是我的样本表与发布决定（粘贴）。请指出：哪类输入没有覆盖、留出集是否被反复调试、结论是否超出样本量。
硬约束：不得补造样本；缺口就写缺口。
```

## 成品样例

一份合格的成果长这样（示例数据，只用于对照格式）：

- 任务：把工单记录整理成客户回复草稿；模型设置固定
- 评分项：事实正确 / 必含工单号与金额 / 三段格式 / 严重错误=编造金额或承诺赔付
- 样本：12 条（正常 6、缺信息 2、长输入 2、矛盾 2），9 条调试、3 条留出
- 参考判断：先人工写下每条必须保留的工单号与金额，再看输出
- A 版：9/12 通过，0 条严重错误；B 版：10/12 通过，**1 条编造金额**
- 决定：不发布 B；保留那条失败样本；用新的 3 条留出样本复测后再判断
- 覆盖缺口：只覆盖一种工单类型，不能外推到所有客户

同样的工作量，但这些**不能用**：

- 让生成模型给自己打分就结束——需要独立规则 + 人工抽查
- 一直调到固定 12 条全对——留出集已被污染，结果不可信
- 用"平均分 8.5"掩盖一条编造金额——严重错误必须单列

## AI边界

- 可以让 AI 做：列样本类别、生成评分表骨架、聚类失败类型、检查覆盖缺口
- 不能让 AI 做：生成虚假的真实样本、替你做最终判定、用平均分掩盖严重错误
- 必须你本人判断：参考事实是否来自真实材料；留出集有没有被调试污染；发布决定能不能接受已知缺口

## 行动步骤

### 定义结果怎样才可用

分别列事实正确、必要字段、格式、不可接受错误；需要专业判断的任务由能胜任的人制定标准。

#### 这一步留下

逐项评分规则与严重错误清单。

### 收集一小组不同样本

从真实情境收集正常、缺信息、长输入和矛盾输入，保留脱敏来源。起步可用12条，但这不证明生产覆盖。

#### 这一步留下

带类别和来源的样本集。

### 先做参考判断并留出样本

人工记录每条应保留的事实与允许变化；将一部分固定为留出集，调试时不据其答案改提示词。

#### 这一步留下

参考判据与调试/留出划分。

### 在相同条件下比较版本

固定输入、模型设置与预算，保存两版输出、通过项、严重错误、耗时和费用；随机性明显的关键样例做少量重复。

#### 这一步留下

逐样例比较表。

### 决定是否发布并保留失败例

把严重回归单列，不以平均分掩盖；留出集若被反复用于调试，另收新样例再判断。

#### 这一步留下

发布决定、已知缺口与失败样本。

## 成果模板

```text
任务/版本/模型设置：
评分项/严重错误：
样本ID/类别/脱敏来源：
参考事实/允许变化：
调试或留出：
版本A输出与判定：
版本B输出与判定：
重复波动/耗时/费用：
失败类型/人工复核：
发布决定/覆盖缺口：
```

## 教学示例

教学模拟，以下数字与情境不是市场调查结果。

12条模拟样例中，A版通过9条，B版通过10条，但B版把一条客户金额编造了。即使总通过数增加，也不能直接发布；先处理这一严重错误并保留样本，之后用新的留出样例检查。

## 常见问题

- 让生成模型给自己打分就结束：需要独立规则与人工抽查。
- 一直修改到固定题全对：记录调试污染，补新留出样本。

## 交付成果

- 版本化样本与判据
- 比较报告和发布决定

## 完成标准

- 每条样本有来源与判定依据
- 包含边界情况和留出样本
- 严重错误独立记录
- 结果明确说明样本量与覆盖局限

## AI参与方式

AI 可辅助聚类失败，不得生成虚假的真实样本；机器评分须经过人工校验。
