# 复盘自媒体带来的使用、付费与投入

## 为什么做

持续回答用户问题、带来使用并控制投入，内容才有经营意义。从一次发布查到真实使用与订单，再决定下一组内容。观看和阅读只说明传播的一部分。

## 开始条件

承接[内容计划](#/task/content-plan)的内容编号、来源台账、成功事件及截止日。练习可用明确标注的教学模拟；没有真实发布就记录准备与卡点，不填写已取得经营结果。

## 学习要点

- 平台计数和产品去重用户
- 首次使用、返回、付费及退款
- 内容成本、归因缺口和下一轮决策

## 可运行起点

```text
一、固定范围与窗口
内容编号：C01 发布版本：___ 渠道：___
内容统计截止日：______ 产品返回窗口：______（例：完成后下一周再次完成）
去重口径：______ 时区：______

二、平台数据（只核对主渠道；缺权限标待取数）
指标名 | 人数或次数 | 原始数 | 统计时间 | 凭据索引
______ | | | |

三、沿内容编号核对同批用户
用户代号 | 来源（已追踪/自述/未知） | 开始 | 首次成功 | 窗口完整 | 再次成功 | 订单/退款
______ | | | | | |

四、算比例（分母为 0 写"不可计算"）
首次成功率 = 首次成功人数 ÷ 开始人数 = ___ ÷ ___ = ___
付费率 = 付款人数 ÷ 首次成功人数 = ___ ÷ ___ = ___
返回率 = 再次成功人数 ÷ 窗口完整人数 = ___ ÷ ___ = ___
直接购买未使用者单列；多条内容不重复算成交。

五、算清投入
制作/剪辑/发布/答疑工时：___
素材/工具/投流/支付费用：___
关联收款 − 退款 − 可归属现金支出 = 本轮现金贡献（不是净利润）
待结算单列；付款人数为 0 → 获客成本写"不可计算"

六、下一组内容
只选一个调整：没人开始查人群入口 / 开始多完成少先修交付 / 完成不买查价值交易 / 制作过重压成本
下一编号：___ 变量：___ 投入上限：___ 复查日：___
```

## AI提示词包

```text
第一轮 · 检查口径
这是我的平台数据与产品台账（粘贴）。请指出：哪些是人数、哪些是次数；有没有把观看数当独立用户；去重口径是否一致。
硬约束：不要替我估数；缺的写"待取数"。

第二轮 · 核对公式
这是我的比例计算（粘贴）。请逐条检查：分子分母是否同批、窗口是否一致、零分母是否写了"不可计算"。
硬约束：不得把不同平台的数合成一个转化率。

第三轮 · 检查成本范围
这是我的投入记录（粘贴）。请指出：哪些成本没算进去、哪些是共用素材需要分摊、待结算是否混进已到账。
硬约束：不得替我估算税费或平台费率。

第四轮 · 选一个下一轮调整
基于这批数据，只给一个最该改的环节（人群入口 / 交付 / 价值交易 / 内容成本），并说明依据。
硬约束：不得同时给多个方向；不得把"小样本前后差异"说成因果。
```

## 成品样例

一份合格的成果长这样（示例数据，只用于对照格式）：

- C01 微信发布，统计截止 10-26，返回窗口为完成后下一周
- 平台：200 次观看（次数，非人数）；产品：12 访问 / 6 开始 / 3 首次成功
- 同批：1 人付款、0 退款；另 1 人来源未知，单列
- 首次成功率 3/6；付费率 1/3（**不是 1/200**）；返回率 1/2（2 人窗口完整，另 1 人待观察）
- 投入：制作 2 小时、答疑 1 小时；素材与工具 5 美元、支付费用 1 美元；已到账 20 美元
- 现金贡献：20 − 5 − 1 = 14 美元（非净利润）
- 下一组：C02 只改"导出前检查"这一步，投入上限 1 小时，复查日 11-02

同样的工作量，但这些**不能用**：

- 用 200 观看算"1/200 付费率"——分母不是独立受众
- 把观看、阅读、点击合成一个跨平台转化率
- 把"想买"补成订单，把未开放收费写成 0 付款

## AI边界

- 可以让 AI 做：检查人数/次数口径、核对公式、检查成本范围、收敛下一轮调整
- 不能让 AI 做：补出用户、订单或流失原因、编造平台数据、把局部现金贡献说成净利润
- 必须你本人判断：同批关系是否成立；窗口是否完整；哪些归因只能标"自述/未知"

## 行动步骤

### 固定复盘范围与观察窗口

沿用C01等编号、发布版本、渠道、匿名用户代号和成功事件。先定内容统计截止日，再按产品节奏定返回窗口，例如完成周报后下一周再次完成。未满窗口标待观察，不能算流失。更新或转载注明版本，同一用户与订单去重。

#### 这一步留下

内容与用户范围、去重口径、时区、内容截止日及返回窗口。

### 按平台取得可用的内容数据

只核对主渠道；下表是检查清单，菜单名与能力以账号当期显示为准，数据未生成或权限不足标待取数。

**微信公众号**：[公众号后台](https://mp.weixin.qq.com/)数据分析中的对应内容，保存可取得的阅读、分享与主动咨询指标、统计时点和人数/次数口径。对照文章承诺与咨询原话，再查产品台账；客服公开入口未覆盖所有账号菜单。

**小红书**：[创作平台](https://creator.xiaohongshu.com/)或自己的笔记数据入口，保存可见阅读/观看、互动和咨询，缺字段注明。分开有人问、有人开始和有人完成，复查商业声明及可用的下一步。

**X**：单帖可见观看数、回复和产品来源记录；先读[观看计数](https://help.x.com/en/using-x/view-counts)，完整面板按权限使用。View counts可能重复且含作者查看，不当作独立用户数。

**YouTube**：按[覆盖面](https://support.google.com/youtube/answer/9314486?hl=zh-Hans)从工作室 → 数据分析 → 内容；具体视频 → 数据分析，看[观众黏度](https://support.google.com/youtube/answer/9314415?hl=zh-Hans)。检查演示前后的中断位置，产品返回另算，样本不足的报告留待观察。

YouTube展示点击率只对应官方规定的缩略图展示范围，不能拿全部观看数除缩略图展示数。各平台曝光、阅读、观看口径分别保留，不合成一个跨平台转化率。

#### 这一步留下

带时间、定义与凭据索引的平台原始数及未知项。

### 沿内容编号核对同批用户

由C01找到来源证据和匿名用户，再查开始、首次成功、再次成功、付款与退款。来源分已追踪、自述、未知；跨设备或多次接触无法可靠识别时保留不确定，多条内容不各算一遍成交。

用同批去重人数算“首次成功人数÷开始人数”“付款人数÷首次成功人数”，只有分母非零、窗口一致且付款者属于该批时才算；直接购买未使用者单列。真实没付款记0；未开放收费或缺订单记录写未开放/未知。

返回率只用观察窗口完整者作分母。回访未完成或未返回的人，原话与推断分开，失联保留未知；视频观看留存不代表产品留存。

#### 这一步留下

可复算的匿名批次表、订单/退款索引、回访和归因缺口。

### 算清这一轮投入

分别记制作、剪辑、发布、答疑及支持工时，另列实际素材、工具、投流和支付费用。共用素材只计一次并说明分摊方法。

关联订单收款减退款，保留币种与期间，再扣本轮可归属现金支出，称“本轮现金贡献”；未含全部经营费用、税费与人工时，不能称净利润。待结算金额另列，不混进已到账；付款人数为0时每名付费者获客成本记不可计算，不能除以0。局部结果不直接证明个人盈利达标。

#### 这一步留下

注明成本范围的现金、未结算与工时表，以及下一轮可承受的投入上限。

### 把反馈变成下一组内容

只选一个主要调整：没人开始先查人群和入口；开始多但完成少先修交付；完成后不买核对价值与交易；付费已有但制作过重就压缩内容成本。

微信把重复咨询做教程/FAQ，小红书补阻塞步骤图，X回复并演示修复，YouTube补卡点教程与说明；只做与真实问题相符的一种。写下一编号、变量、投入上限、复查日和继续/调整/等待/停止条件。小样本前后差异作为线索，不直接认定因果。

#### 这一步留下

下一轮内容简报、决定与复查条件。

## 教学示例

教学模拟，无真实推广或经营结果。C01平台报告200次观看；产品台账有12名访问、6名开始、3名首次成功，其中1名付款20美元，无退款；另有1名来源未知，单列。假定付款者属于这3名首次成功者。

本批首次成功为3/6，付费为1/3，不能算1/200称“独立受众付费率”。3名完成者只有2名拥有完整下一周窗口，1名再次完成，返回为1/2，另1名待观察。

制作2小时、答疑1小时；本轮独占素材与工具支出5美元，支付费用假设有凭证为1美元，20美元已到账。本轮现金贡献20−5−1＝14美元；未计全部运行、税费及人工，不能认定净利润。先查未完成者的阻塞，用1小时补C02演示后复查。价格和费用不是平台标准。

## 常见问题

- 看不到统计：登记权限与待取数，用产品台账补实际行为，不编造数据。
- 没有付款：区分0、未开放和未知，不以“想买”补订单。
- 归因不清：保留自述与未知，不将品牌搜索、私信和参数访问拼成确定漏斗。
- 一直发文没有产品改进：把有证据的阻塞交给产品任务后再验证。

## 交付成果

- 内容到实际使用、再次使用及付款的匿名批次表
- 平台口径、归因缺口和本轮收支工时
- 一项有投入上限和复查条件的下轮内容简报

## 完成标准

- 内容编号承接发布台账，平台次数和产品去重用户分开
- 成功、再次使用、付款与退款有依据，待观察和未知单列
- 比例分母及窗口一致，零分母未计算，订单未重复归因
- 现金贡献注明成本范围，人工工时单列，下一轮有投入上限与复查条件

## AI参与方式

辅助汇总脱敏数据、检查公式和提炼选题；核对同批关系与遗漏，不让AI补出用户、订单或流失原因。
